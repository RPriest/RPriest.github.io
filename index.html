🎬 End-to-End DevSecOps Pipeline on AWS EKS (Netflix Clone)

A 4-phase build taking a Netflix-clone frontend from a bare AWS account to a fully monitored, GitOps-deployed application on Kubernetes. AWS account hardening → a 20+ stage Jenkins pipeline with 8+ security scanners → ArgoCD GitOps deployment to EKS → centralized vulnerability management in DefectDojo → Prometheus/Grafana monitoring.

AWS EKS Jenkins ArgoCD SonarQube Semgrep Trivy OWASP Dependency-Check ZAP CycloneDX DefectDojo Prometheus / Grafana OIDC

🔴 Aggregated Findings: 113 findings centralized in DefectDojo across 8+ independent scanners

🔴 DAST: 16 alerts caught by ZAP against the live AWS deployment

🔴 SBOM: 100 known CVEs surfaced across 34 dependencies via CycloneDX + osv-scanner

🟡 OpenSSF Scorecard: Security posture improved from 2.6 → 2.8

🟢 Zero Long-Lived Credentials: OIDC end to end for CI/CD — no static AWS keys anywhere

🟢 GitOps Architecture: Jenkins never touches the cluster directly — only ArgoCD does, limiting blast radius on compromise
