🔐 PyGoat DevSecOps Pipeline

A fully automated DevSecOps security pipeline built on PyGoat — a deliberately vulnerable Python web application. This project demonstrates real-world security controls embedded across the entire software delivery lifecycle, from code commit to production deployment on AWS EC2.

GitHub Actions Semgrep CodeQL ZAP by Checkmarx AWS EC2 CloudFormation CycloneDX Dependabot OpenSSF Scorecard osv-scanner

🔴 SAST: 199 code scanning findings identified by CodeQL — Code Injection, SSRF, Uncontrolled Command Line vulnerabilities

🔴 DAST: 16 alerts detected by automated ZAP baseline scan against live AWS deployment

🔴 SBOM: 100 known vulnerabilities identified across 34 packages — 99 with available fixes

🟡 OpenSSF Scorecard: Security posture improved from 2.6 → 2.8 after implementing branch protection controls

🟢 Dependency Review: Successfully blocked GitPython 3.1.29 (Critical — RCE) from merging via PR gate

🟢 Branch Protection: Zero unreviewed commits reaching master — CODEOWNERS enforcing mandatory code review on every PR
